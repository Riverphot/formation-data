# Projet 5 : Création de base de données immobilière

<br/>

## 🎬 Scénario  
En tant que Data Analyst chez Laplace Immo, vous êtes chargé de concevoir et mettre en place une base de données relationnelle complète afin d’analyser les transactions immobilières et foncières. Ce projet s’inscrit dans une stratégie de valorisation des données à l’échelle nationale, pilotée par la direction technique. 

<br/>

## 🎯 Objectifs  

- Analyser les fichiers de données des transactions immobilières
- Élaborer un dictionnaire de données
- Préparation des données avec conformité au RGPD  
- Concevoir un schéma relationnel en 3NF  
- Créer et implémenter la base dans un SGBD 
- Réaliser des requêtes SQL complexes pour répondre aux besoins métiers

<br/>

## 🛠 Outils utilisés  
- Excel
- Power Query
- SQL

<br/>

## 📈 Étapes du projet  

- Exploration et préparation des données  
- Sélection des variables utiles, suppression des doublons
- Mise en conformité RGPD 
- Construction d’un dictionnaire de données 
- Modélisation du schéma relationnel (3NF), définition des clés primaires et étrangères  
- Implémentation dans SQLite  
- Création des tables et des contraintes  et chargement des données 
- Requêtes SQL : Extraction d’indicateurs de performance, analyse des tendances par région, type de bien ou population  
- Création de vues pour optimisation des requêtes
